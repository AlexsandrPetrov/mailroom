# Mailroom

Панель управления почтовым сервером (Postfix + Dovecot 2.4 + Rspamd) и веб-почта для пользователей. Debian 13, Flask, PostgreSQL.

Домены, ящики и алиасы хранятся в PostgreSQL Mailroom. Postfix и Dovecot читают их напрямую через представления `mail_domains`, `mail_users`, `mail_aliases`, `mail_sender_login` (роль `mailserver`, только `SELECT`), поэтому изменения в панели действуют сразу, без перезагрузки сервисов.

## Возможности

**Панель администратора** (`https://СЕРВЕР:5080/`)

- Обзор: сервисы, очередь, место под почту, статистика Rspamd.
- Рекомендации: живая проверка DNS, TLS, сервисов, чёрных списков, служебных адресов и безопасности панели — с объяснением и способом исправить.
- Домены и DNS: квоты, включение и отключение, мастер записей MX, A, PTR, SPF, DKIM, DMARC, TLS-RPT, SRV с проверкой опубликованного. Мастер учитывает уже существующие SPF и DMARC: объединяет SPF в одну запись и не ослабляет более строгую политику DMARC.
- DKIM: ключ 2048 бит создаётся в панели; подпись включается только после проверки публикации ключа в DNS; ротация с новым селектором без перерыва подписи.
- Ящики: квоты с занятым местом, отключение, сброс пароля, удаление с переносом писем в архив `/var/vmail/.deleted`.
- Алиасы и пересылка, включая catch-all (`*`). Получатели-ящики могут отправлять от имени алиаса.
- Очередь: просмотр с причиной задержки, повторная доставка, задержать, освободить, удалить.
- Трассировка письма по адресу, ID очереди или Message-ID.
- Проверки: DNS любого домена, SMTP (EHLO, STARTTLS, AUTH), сертификат TLS, чёрные списки, тестовое письмо, разбор заголовков (SPF/DKIM/DMARC глазами получателя, путь и задержки).
- Логи, журнал действий, конфигурация Postfix, настройки с применением к Postfix.
- Пользователи с ролями (администратор, оператор, наблюдатель), 2FA (TOTP), блокировка перебора.

**Веб-почта** (`https://СЕРВЕР:5080/mail`) — по техзаданию [docs/PROMPT_WEBMAIL.md](docs/PROMPT_WEBMAIL.md)

- Папки (включая вложенные и с кириллицей), поиск, фильтры, массовые действия, перетаскивание.
- Безопасный показ HTML: изолированный iframe без скриптов, строгая CSP, внешние картинки скрыты до нажатия «Показать изображения».
- Ответ, ответ всем, пересылка с вложениями, черновики, подпись, адресная книга с автодополнением.
- Автоответ, переадресация и фильтры — через Sieve.
- Смена пароля, активные сеансы, квота, параметры для почтовых программ и корневой сертификат.
- Лимиты отправки (по умолчанию 100 получателей в час, 50 в письме).
- Тёмная тема, телефонная раскладка, горячие клавиши (`c`, `r`, `/`, `Delete`, `Esc`).

Пароль пользователя веб-почты нигде не хранится: панель проверяет его по своей базе, а к IMAP и ManageSieve подключается через мастер-пользователя Dovecot, разрешённого только с `127.0.0.1`. Сессии хранятся на сервере и завершаются при отключении ящика или смене пароля.

## Установка и обновление

```bash
git clone … mailroom && cd mailroom
sudo bash deploy/install.sh --hostname mail.example.com --ip 192.0.2.10
```

Скрипт можно запускать повторно — это и есть обновление. Он:

- ставит пакеты (Postfix, Dovecot с PostgreSQL и Sieve, Rspamd, Redis, Fail2ban, gunicorn);
- создаёт `vmail` и `/var/vmail`, собственный CA и сертификат сервера (`/etc/mailroom/tls`);
- создаёт роль `mailserver`, SQL-карты Postfix, самостоятельный `dovecot.conf` с мастер-пользователем, Sieve-правило «спам → Спам», DKIM-подпись Rspamd по `selectors.map`, Fail2ban;
- устанавливает код в `/opt/mailroom`, данные — в `/var/lib/mailroom`, секреты — в `/etc/mailroom.env`;
- ставит помощника `/usr/local/sbin/mailroom-helper` (очередь, квоты, применение настроек Postfix) с правом `sudo` только на него.

Предыдущие конфиги каждый раз сохраняются в `/root/mailroom-backup-ВРЕМЯ`. Уже созданные секреты, CA и ключи DKIM не перевыпускаются.

Стартовый пароль администратора — в `/var/lib/mailroom/.bootstrap-admin`; после смены пароля в панели файл удаляется.

## Порты

| Порт | Назначение | Доступ |
| --- | --- | --- |
| 25 | приём почты | все |
| 587, 465 | отправка с паролем (STARTTLS / TLS) | все |
| 993, 995 | IMAPS, POP3S | все |
| 5080 | панель и веб-почта (HTTPS) | LAN |
| 143, 4190 | IMAP и ManageSieve для веб-почты | только localhost |
| 5432, 6379, 11332–11334 | PostgreSQL, Redis, Rspamd | только localhost |

## Безопасность

- CSP без inline-скриптов, `X-Frame-Options`, `nosniff`, cookie `__Host-` с `Secure`/`HttpOnly`/`SameSite=Lax`, CSRF на всех изменяющих запросах.
- Пароли ящиков — SHA512-CRYPT (проверяет Dovecot), пароли панели — PBKDF2.
- 5 ошибок входа за 15 минут — блокировка по логину и IP; простой админ-сессии — 1 час, веб-почты — 30 минут.
- Внешние команды запускаются без shell; помощник принимает только фиксированные подкоманды с проверкой аргументов.

## Структура

- `app.py` — панель и API администратора, схема БД, DNS-мастер, рекомендации.
- `webmail.py` — веб-почта (Blueprint).
- `mailcore.py` — IMAP, ManageSieve, Sieve, DKIM, DNS, TLS, разбор заголовков.
- `templates/`, `static/` — интерфейс без сборщика (ванильный JS, SVG-иконки).
- `deploy/` — установщик и помощник.
- `docs/PROMPT_WEBMAIL.md` — техническое задание на веб-почту.
